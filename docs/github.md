# Public code and private results

[Homabazireh/fine-mapping](https://github.com/Homabazireh/fine-mapping) is public. Publish Python and R code, tests and generic methodological documentation only. Do not publish cohort result tables, figures, interpretation reports, participant metadata, genotypes or credentials here.

[Homabazireh/fine-mapping-2](https://github.com/Homabazireh/fine-mapping-2) is private. It holds the code, all cohort outputs and the checked project-data release archives. Verify private visibility before every upload of data or results; do not change visibility or add collaborators. Follow its `PRIVATE_DATA.md` to restore large inputs.

Before pushing, check the remote, review staged paths and content, run relevant Python/R checks and `git diff --check`, then commit and push normally. Do not force-push or overwrite another person's work. Copy generated outputs only to the verified private destination.

Removing files from the current public branch does not rewrite older Git commits or retract copies already downloaded.
