# Private figures and results

All cohort figures, result tables and interpretation reports are stored in [private fine-mapping-2](https://github.com/Homabazireh/fine-mapping-2). The public repository contains their reproducible Python and R source code only. Private repository access is required to open the outputs.

See its `docs/figures/`, `docs/contrasts/` and regional-figure index for the current outputs, and `PRIVATE_DATA.md` for complete archived runs. Earlier versions remain in public Git history; this directory does not distribute current results.
