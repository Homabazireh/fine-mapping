# Private generated outputs

Analysis runs, genotype summaries, statistics, figures, interpretation reports and validation results are local/private outputs. They are ignored by Git in the public repository. Preserve earlier runs and use a new directory when repeating an analysis.

Each completed run contains input provenance, settings, tables and a completion marker. Keep participant-level and aggregate outputs together in the private archive; use the private repository's figure/report indexes for browsing. See the public analysis documentation for commands and the private `PRIVATE_DATA.md` for data restoration.

Synthetic demo outputs demonstrate software behavior only. They must never be presented as evidence about real participants.
